# Font Pairing Reference

Curated font recommendations by purpose, sourced from [garrytan/gstack](https://github.com/garrytan/gstack) design-consultation skill.

## Display / Hero Fonts
| Font | Character | Best For |
|------|-----------|----------|
| Satoshi | Clean geometric sans | Tech, SaaS, modern products |
| General Sans | Friendly geometric | Consumer apps, startups |
| Instrument Serif | Elegant contrast | Editorial, luxury, content |
| Fraunces | Warm old-style variable | Brand-heavy, opinionated products |
| Clash Grotesk | Tight, bold display | Marketing, headlines |
| Cabinet Grotesk | Rounded geometric | Friendly dashboards, consumer |

## Body Fonts
| Font | Character | Best For |
|------|-----------|----------|
| Instrument Sans | Clean, readable | Pairs with Instrument Serif |
| DM Sans | Geometric, friendly | General-purpose body text |
| Source Sans 3 | Neutral, professional | Enterprise, data-heavy apps |
| Geist | Modern, technical | Developer tools, SaaS |
| Plus Jakarta Sans | Warm geometric | Consumer products, mobile |
| Outfit | Clean variable | Versatile, works at all sizes |

## Data / Table Fonts
| Font | Feature | Best For |
|------|---------|----------|
| Geist (tabular-nums) | Fixed-width numbers | Financial data, metrics |
| DM Sans (tabular-nums) | Aligned columns | Dashboards, tables |
| JetBrains Mono | Monospace, ligatures | Code + data hybrid |
| IBM Plex Mono | Neutral monospace | Technical documentation |

## Code Fonts
| Font | Feature | Best For |
|------|---------|----------|
| JetBrains Mono | Ligatures, readable | IDE-like code blocks |
| Fira Code | Popular ligatures | Code snippets |
| Berkeley Mono | Premium, clean | High-end developer tools |
| Geist Mono | Matches Geist system | Vercel-style projects |

## Font Blacklist (never recommend)
Papyrus, Comic Sans, Lobster, Impact, Jokerman, Bleeding Cowboys, Permanent Marker, Bradley Hand, Brush Script, Hobo, Trajan, Raleway, Clash Display, Courier New (for body)

## Overused Fonts (avoid as primary)
Inter, Roboto, Arial, Helvetica, Open Sans, Lato, Montserrat, Poppins — only if user specifically requests.
